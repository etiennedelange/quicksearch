# Release History

Tracks published releases of QuickSearch
(`github.com/etiennedelange/quicksearch`), built and published by the
`v*.*.*` tag workflow in `.github/workflows/release.yml`. The GitHub
release itself remains the source of truth for assets and full notes —
this file is a quick local reference so a session doesn't need to hit the
GitHub API to know what's currently live.

Update this when a new tag is released: add an entry with the version,
date, and a one-line summary of what shipped.
